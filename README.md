# Amos Tu（涂云勐）电子名片

## 发布名片网页

1. 解压 ZIP，将 `index.html`、`Amos-Tu.vcf` 和 `bpg-official-logo.png` 等文件上传到 GitHub 仓库 `main` 分支的根目录，保持在同一层。
2. 在仓库打开 **Settings → Pages**，选择 **Deploy from a branch**，设置为 `main` 和 `/(root)`，点击 **Save**。
3. 发布完成后，在 **Settings → Pages** 点击 **Visit site**。打开网页，确认 **Save Contact** 能下载通讯录文件。

已有 Pages 站点时，可将这组文件放到发布目录下的 `amos-tu/` 子目录，访问站点下的 `/amos-tu/`。

[GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site#viewing-your-published-site)

## 生成名片二维码

复制发布后的完整 HTTPS 网页网址，用它生成二维码。先用手机原生相机扫码，确认能打开名片网页，并通过 **Save Contact** 导入联系人，再把二维码放到实体名片上。
